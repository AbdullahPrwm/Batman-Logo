# 📋 Project Overview
This project recreates the iconic Batman logo as a 3D CAD model using Onshape.

## ✨ Features
- 🦇 Accurate Batman logo design
- 📏 Fully constrained sketch
- 📦 3D solid model created using Extrude
- 🎯 Clean and symmetrical geometry
- ⚙️ Suitable for CAD practice, 3D printing, or laser cutting

# 🚀 Skills Demonstrated
- CAD Sketching
- 3D Modeling
- Geometric Constraints
- Spline & Arc Design
- Extrusion
- Design Accuracy
